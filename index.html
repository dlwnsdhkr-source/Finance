📖 Firestore 무료 연결 & 보안 규칙(Rules) 가이드

1. console.firebase.google.com 접속 → 기존 프로젝트(또는 새 프로젝트) 선택.

2. 프로젝트 설정(⚙️)에서 웹 앱의 firebaseConfig 코드를 복사해 위 칸에 그대로 붙여넣습니다.

3. 좌측 Firestore Database → 규칙(Rules) 탭에 아래 코드를 넣고 게시(Publish)를 누르세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /debt_rooms/{roomId} {
      allow read, write: if true;
    }
  }
}
